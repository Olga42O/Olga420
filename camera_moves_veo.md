# Библиотека движений камеры для промптов Veo

Термины пишутся в промпте по-английски: Veo лучше понимает их так. Рядом дан смысл по-русски и совет, когда использовать.
Правило: **одно главное движение камеры на клип**, максимум два (основное + лёгкое дополнение). Скорость и амплитуду задавайте словами: slow, subtle, gentle, steady.

## 1. Базовые (безопасные, дают стабильный результат)

| Термин для промпта | Что делает | Когда использовать |
|---|---|---|
| static shot, locked-off tripod | Камера неподвижна, движется только сцена | Атмосферные кадры: туман, свет, листва |
| slow push-in / dolly in | Медленно приближается к объекту | Нарастание эмоции, акцент на детали |
| slow pull-out / dolly out | Отъезд, открывается пространство | Раскрытие масштаба, финал сцены |
| pan left / pan right | Поворот камеры по горизонтали на месте | Обзор пространства |
| tilt up / tilt down | Поворот по вертикали | Снизу вверх по стволам к кронам и наоборот |
| tracking shot / follow shot | Камера едет рядом с объектом | Движение героя, идущий персонаж |
| lateral dolly / truck left-right | Боковой проезд параллельно сцене | Ряд стволов, «параллакс» леса |
| slow zoom in / zoom out | Оптическое приближение без смены позиции | Мягкий акцент (используйте реже dolly) |

## 2. Выразительные

| Термин | Что делает | Когда использовать |
|---|---|---|
| orbit / arc shot (slow 90° arc) | Камера огибает объект по дуге | Героиня или центральный объект, «раскрытие» |
| crane up / crane down | Подъём или спуск камеры | Старт и финал сцены, переход к масштабу |
| pedestal up / down | Вертикальный подъём камеры без наклона | Подъём вдоль ствола, раскрытие вида |
| rack focus | Фокус переходит с переднего плана на задний | Смена акцента внутри кадра |
| dolly zoom (vertigo effect) | Дальше фон «втягивается», объект неподвижен | Тревога, момент осознания. Использовать редко |
| parallax slide | Передний план движется быстрее заднего | Глубина леса, слои веток |
| over-the-shoulder push | Приближение из-за плеча героя | Взгляд героя на пейзаж |
| low-angle push-in | Приближение снизу вверх | Величие деревьев, масштаб |
| top-down / overhead shot | Вид строго сверху | Тропа, корни, вода |
| Dutch angle (tilted horizon) | Наклон горизонта | Тревожное, нереальное настроение |

## 3. Динамичные (только для кульминаций, увеличивают риск артефактов)

| Термин | Что делает | Замечание |
|---|---|---|
| FPV drone flight through trees | Полёт «от первого лица» между стволами | Задавайте smooth, controlled speed |
| aerial drone shot, slowly ascending | Облёт сверху, подъём над лесом | Хорош для начала или конца |
| whip pan | Резкий поворот, размытие, как переход | Годится как «склейка» между клипами |
| crash zoom | Резкий наезд | Только для удара в музыке |
| handheld, subtle shake | Лёгкая ручная дрожь | Документальность, живость. Слово subtle обязательно |
| steadicam glide | Плавный «парящий» проход за героем | Основной способ дать плавный follow |
| bullet time / frozen orbit | Время замирает, камера кружит | Сложно для Veo, нужны отдельные дубли |

## 4. Скорость и характер (добавлять к любому движению)
`very slow` · `slow and steady` · `gentle` · `smooth and continuous` · `subtle` · `accelerating` · `decelerating to a stop` · `floating, dreamlike`

## 5. Шаблон промпта Veo для кадра

```
[Что на изображении / сохранить как есть]. 
Camera: [движение + скорость]. 
Motion in scene: [что двигается: ветер в листве, туман, свет, волосы, ткань, вода].
Lighting & mood: [свет, время суток, настроение].
Style: [единый блок стиля клипа]. 
Duration: [4–8 s]. No text, no logos, no camera cuts.
```

Приёмы:
- Для оживления картинки начинайте с «Keep the composition, subject and style of the reference image».
- Для стыков между клипами заканчивайте клип движением, которое продолжит следующий (push-in → push-in, crane up → crane down).
- Если артефакты: упрощайте до static + движение в сцене (ветер, туман, свет).
