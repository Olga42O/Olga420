# «Плавучие сады» — 45 кадров (Midjourney + Veo)

## Как пользоваться
1. **Мастер-референсы (один раз).** Сгенерируйте/выберите 2–3 кадра героини: ваш пустынный портрет, 3/4 и профиль в нейтральном свете. Положите в папку. Костюм из пустынного кадра полностью перенесён в блок CHAR ниже.
2. **В каждом кадре**: в «Attach to prompt» подключайте мастер-референс героини; в Style reference — один и тот же кадр-эталон мира (первый удачный кадр озера); для кадров одной локации добавляйте предыдущий удачный кадр этой сцены.
3. **Настройки панели**: 16:9, Raw, Stylization низкая–средняя, Weirdness 0, Variety средняя (чуть выше — для разнообразия композиций), HD.
4. **Контрольная сверка**: лицо (зелёные глаза, серебряные метки), чёлка, перья на плечах, бронзовый пояс, коричневый плащ. Расхождение чините в Quick Edit/Editor до Veo.
5. **Veo**: стартовый кадр = выбранная картинка; вставляйте строку «Veo». Клипы 4–8 с. Для кадров без лица (вставки) подключайте тот же референс героини, если ваш Veo это умеет.
6. Гости (женщины на лодках) должны иметь **другие лица и светлую льняную одежду**, чтобы героиня оставалась узнаваемой.
